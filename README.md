## FAQ

### Is OmniPatch safe to use on my computer?

OmniPatch is developed with user security in mind. We perform regular security scans and the tool does not contain any malicious code. However, as with any system modification tool, we recommend using it in a controlled environment.

### Which AI applications are currently supported?

OmniPatch supports ChatGPT, Claude, Perplexity, Microsoft Copilot, GitHub Copilot, Cursor, Devin, and JetBrains AI Assistant. We plan to add support for more applications in future updates.

### How often do you release updates for new AI features?

We aim to release updates within 48-72 hours after major feature or version changes in the supported AI platforms. Major updates that break compatibility will be addressed as a priority.

### Do I need to keep OmniPatch running in the background?

No. OmniPatch modifies the application files or configurations once. After the initial activation, the premium features remain unlocked until the target application is updated by its developer, which may require a new patch.

### Will using OmniPatch void my warranty or violate terms of service?

OmniPatch modifies software to unlock features you may not have paid for, which likely violates the terms of service of the respective applications. Use it at your own discretion and risk.

### What should I do if an application update breaks the patch?

If a supported app updates and reverts the changes, simply re-run OmniPatch on the newly updated application. We work quickly to ensure compatibility with the latest versions.

### Is there a version for macOS or Linux?

Currently, OmniPatch is a Windows-only desktop application. We are evaluating the feasibility of developing versions for other operating systems based on user demand.

### How do I know which features are unlocked for a specific app?

The OmniPatch interface provides a detailed list of unlocked features for each application before you apply the patch. You can also refer to the documentation on the repository page.
